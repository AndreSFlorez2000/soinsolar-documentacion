# Actividad 1 — Registro de herramientas seleccionadas

## Propósito

Seleccionar y dejar preparadas las tecnologías necesarias para construir una aplicación web básica, visualmente clara, segura y fácil de mantener.

## Selección definitiva

| Componente | Herramienta | Uso en el proyecto |
|---|---|---|
| Interfaz | HTML5 y CSS3 | Estructura y estilo propio de las pantallas. |
| Diseño adaptable | Bootstrap 5.3.8 | Formularios, rejilla, tablas y componentes responsive. |
| Interacción | JavaScript ES6 | Navegación, validaciones, filtros y actualización de vistas. |
| Datos y autenticación | Supabase | PostgreSQL, autenticación, RLS y almacenamiento. |
| Gráficos | Chart.js 4 | Indicadores y comportamiento mensual. |
| Versionamiento | Git y GitHub privado | Historial del código, documentación y control de cambios. |
| Desarrollo | Visual Studio Code | Edición y depuración. |
| Despliegue | Vercel o Netlify | Publicación HTTPS del frontend. |

## Justificación

La selección evita un backend propio en la primera versión y reduce el tiempo de configuración. Bootstrap y JavaScript permiten construir una interfaz empresarial sin un framework pesado; Supabase aporta una base PostgreSQL real y controles de acceso. El repositorio se mantendrá privado porque el proyecto corresponde a información y procesos internos de SOINSOLAR.

## Estado
