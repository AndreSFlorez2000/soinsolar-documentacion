# Actividad 3 — Estructura inicial documentada

```text
soinsolar-control/
├── docs/objetivo-3/          Evidencias académicas de desarrollo
├── scripts/                  Servidor y utilidades de desarrollo
├── src/assets/css/           Estilos corporativos y responsive
├── src/assets/js/config*     Configuración local no sensible
├── src/assets/js/data/       Datos demostrativos
├── src/assets/js/domain/     Fórmulas y reglas financieras
├── src/assets/js/services/   Conexión con Supabase
├── supabase/                 Configuración y futuras migraciones
├── tests/                    Pruebas automáticas iniciales
├── index.html                Entrada del frontend
├── package.json              Scripts del proyecto
└── README.md                 Instalación, uso y alcance
```

La estructura separa presentación, reglas financieras, acceso a datos, configuración y documentación. Esto permite sustituir los datos demostrativos por consultas reales sin rehacer las pantallas.
