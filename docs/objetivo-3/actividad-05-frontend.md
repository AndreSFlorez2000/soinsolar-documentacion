# Actividad 5 — Frontend configurado

## Resultado

Se configuró una aplicación web responsive basada en HTML5, Bootstrap 5.3.8, CSS propio y JavaScript ES6. La primera versión contiene:

- Inicio de sesión y acceso al prototipo.
- Menú lateral por módulos.
- Selector de periodo activo.
- Dashboard con indicadores, gráfico mensual, alertas y proyectos recientes.
- Detalle de proyecto con contrato, avance financiero, facturación, pagos, costos, saldo e historial.
- Navegación preparada para seguimiento mensual, finanzas, costos, reportes y administración.
- Fórmulas financieras separadas y cubiertas por pruebas automáticas.
- Diseño adaptable a computador, tableta y móvil.

## Datos demostrativos

Los valores del prototipo permiten verificar presentación y cálculos. No corresponden a una carga productiva y deberán reemplazarse por consultas autorizadas a Supabase en las siguientes actividades.

## Prueba de ejecución

```bash
npm run dev
npm test
```

El proyecto no necesita instalar dependencias para ejecutar el servidor local ni las pruebas iniciales.
